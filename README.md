# Physical AI

An interactive learning platform for physical AI and autonomous systems — maritime, aviation, and ground robotics — featuring 3D digital-twin explorers, sensor/control simulators, and a hands-on ROS concepts guide, all built with React and Three.js.

## Usage

```bash
npm install
npm run dev
```

Then open the printed local URL in your browser. Use `npm run build` to produce a production build in `dist/`, and `npm run preview` to preview it locally.
